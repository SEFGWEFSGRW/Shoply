# Shoply | شوبلي — النسخة المعدلة

هذه النسخة تحافظ على فكرة وشكل شوبلي، مع 3 تعديلات أساسية:

1. **الدعم شغال:** زر «إحنا قريبين» يفتح نموذج دعم، والرسائل تصل إلى لوحة الإدارة في قسم «رسائل الدعم».
2. **الإدارة محمية:** كلمة المرور ليست داخل الكود. تسجيل الدخول يتم عبر Supabase Auth، وبعده يتم التأكد من وجود المستخدم في جدول `admin_users`.
3. **لا توجد منتجات افتراضية:** المتجر يبدأ فارغًا، والمنتجات تظهر فقط بعد إضافتها من لوحة الإدارة. إذا كانت قاعدة بياناتك تحتوي بالفعل على المنتجات الثلاثة القديمة، شغّل `supabase/clean_products.sql` مرة واحدة.

## إعداد الإدارة
1. أنشئ مستخدم الإدارة من Supabase Authentication > Users واختر الإيميل وكلمة المرور بنفسك.
2. بعد إنشاء المستخدم، خذ User UID من Supabase ونفّذ:

```sql
insert into public.admin_users (user_id)
values ('PUT_ADMIN_USER_UUID_HERE');
```

لا تضع كلمة المرور في أي ملف من المشروع.

## التشغيل
```bash
npm install
npm run dev
```

## متغيرات البيئة
ضع في `.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

لا تستخدم Service Role Key في الواجهة.
